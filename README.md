# A Day of One-Line Pitches — v2

One line to convince a friend who has never written code to let an AI agent
build their first app on make.fun.

## The pitch

> Tell it your idea over coffee — by tonight, there's an app with your name on it.

## Why this line

It leads with a concrete payoff (an app with *your* name on it, tonight),
frames the ask as a chat over coffee — no jargon, no learning curve — and
keeps it short enough to land in a single read. Nothing is overpromised:
an agent on make.fun really does build the app from a plain-words idea.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the pitch to `/output/entry.txt`.
